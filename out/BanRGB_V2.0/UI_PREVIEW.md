## 💻 实现细节

### QSS 渐变语法
```css
background: qlineargradient(
    x1:0, y1:0, x2:1, y2:1,
    stop:0 #color1,
    stop:1 #color2
);
```

### 阴影效果代码
```python
shadow = QGraphicsDropShadowEffect()
shadow.setBlurRadius(25)
shadow.setColor(QColor(0, 255, 65, 150))
shadow.setOffset(0, 0)
widget.setGraphicsEffect(shadow)
```

### 样式切换
```python
widget.setObjectName("connectedStatus")
widget.setStyleSheet(widget.styleSheet())  # 刷新
```

## 🚀 性能考虑

### 优化建议
- 阴影效果限制在关键元素
- LED 网格避免过度更新

- 动画使用 CSS 而非定时器
