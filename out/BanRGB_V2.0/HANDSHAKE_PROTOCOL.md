# BanRGB V2.0 主动握手协议文档

## 概述

BanRGB V2.0 采用**主动握手机制**来建立上位机与下位机（AIR001_BanRGB_V2）之间的连接。该机制确保只有正确的设备才会被连接，避免误连接到其他串口设备。

## 握手流程

### 1. 上位机主动扫描

上位机启动后会执行以下操作：
1. **扫描所有可用串口**：使用 `serial.tools.list_ports.comports()` 获取系统中所有可用的串口列表
2. **逐个尝试连接**：对每个串口创建独立的通信线程
3. **发送握手命令**：向每个串口发送握手命令 `'E'`（单字符，无换行符）
4. **等待响应**：等待设备响应，默认超时时间为 1 秒

### 2. 下位机响应握手

下位机（AIR001_BanRGB_V2固件）在串口中断中检测握手命令：

```c
void USART1_IRQHandler(void)
{
    if (__HAL_UART_GET_FLAG(&UartHandle, UART_FLAG_RXNE) != RESET)
    {
        ch = (uint16_t)READ_REG(UartHandle.Instance->DR);
        
        // 检测握手命令 'E' (0x45)
        if(ch == 'E' || ch == 0x45) {
            Handle_Handshake();  // 发送握手响应
            count = 0;
        }
        else {
            // 正常数据处理
            rx_buffer[count++] = ch;
            if(count > (rgb_t.total*5)-1) count = 0;
        }
    }
    HAL_UART_IRQHandler(&UartHandle);
}
```

握手响应函数：
```c
void Handle_Handshake(void)
{
    const char* response = "BANRGB_OK\n";
    HAL_UART_Transmit(&UartHandle, (uint8_t*)response, strlen(response), 1000);
}
```

### 3. 上位机验证响应

上位机接收到响应后进行验证：
- **检查响应内容**：响应必须包含 `"BANRGB_OK"` 字符串
- **匹配成功**：建立连接，关闭其他串口线程，开始正常通信
- **匹配失败**：关闭该串口，继续尝试下一个

### 4. 连接建立

握手成功后：
- 上位机标记该串口为已连接状态
- 发出连接成功信号 `connected.emit(port)`
- 停止重试定时器
- 清空数据缓冲区，准备接收LED控制数据

## 协议参数配置

在 `config.ini` 文件中配置握手参数：

```ini
[Handshake]
; 主动握手命令（单字符'E'）
command = E
; 握手超时时间（秒）
timeout = 1.0

[MatchCommand]
; 期望的握手响应（必须包含此字符串）
command = BANRGB_OK
```

## 错误处理

### 握手超时
- **错误码**：`ERROR_HANDSHAKE_TIMEOUT (1005)`
- **原因**：在超时时间内未收到响应
- **处理**：关闭该串口，继续尝试下一个

### 握手失败
- **错误码**：`ERROR_HANDSHAKE_FAILED (1006)`
- **原因**：收到响应但不包含 `"BANRGB_OK"`
- **处理**：关闭该串口，继续尝试下一个

### 串口占用
- **错误码**：`ERROR_PORT_BUSY (1002)`
- **原因**：串口被其他程序占用
- **处理**：跳过该串口，继续尝试下一个

### 无可用串口
- **原因**：系统中没有可用的串口设备
- **处理**：启动重试定时器，定期重新扫描

## 优势

1. **自动识别设备**：无需用户手动选择串口，自动找到正确的设备
2. **避免误连接**：只有响应正确握手的设备才会被连接
3. **多设备支持**：可以同时扫描多个串口，快速找到目标设备
4. **容错性强**：即使某些串口无法打开或响应错误，也不会影响其他串口的尝试
5. **自动重连**：连接断开后自动重新扫描和连接

### 常见问题排查

#### 问题：握手超时
- 检查下位机是否正确烧录固件
- 检查串口波特率是否匹配（默认 115200）
- 检查串口线是否连接正常

#### 问题：收到错误响应
- 确认下位机固件版本为 AIR001_BanRGB_V2
- 检查下位机的握手响应函数是否正确实现
- 使用串口调试工具手动发送 'E' 测试下位机响应

#### 问题：无法找到串口
- 检查USB连接
- 检查驱动是否安装（CH340/CP2102等）
- 在设备管理器中确认串口是否正常识别
