## 🎯 交互细节

### 字体
- **标题**: Consolas/Courier New (等宽字体)
- **大小**: 24px (标题) / 14px (状态) / 12px (控件)
- **加粗**: 所有重要文字
- **字间距**: 标题加宽 3px，科技感十足

### 边框
- **厚度**: 2px 
- **圆角**: 6-12px (根据元素大小)
- **样式**: 实线 + 霓虹色

### 阴影
- **模糊半径**: 20-25px
- **颜色**: 半透明霓虹色 (Alpha: 100-150)
- **偏移**: 0, 0 (向外发散)

### 渐变
- **方向**: 从左到右 / 从上到下
- **颜色**: 深色到浅色 (同色系)
- **平滑**: 无明显色带
